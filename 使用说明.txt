牛马脱敏器联机便携包 · v1.1.0

适用：Windows 11 或 Windows 10 22H2，64 位 Intel / AMD。
Windows 客户端用系统自带的 .NET Framework。房间服务需要的 Node.js 和
Cloudflare 隧道工具已放在 runtime 文件夹，不需要安装 Node.js 或 Docker。
保持 niuma.exe、launch.mjs、runtime 和 room 在同一个解压目录。

一、异地联机
1. 右键 ZIP 选择「全部解压缩」，进入解压后的文件夹。
2. 双击 niuma.exe。已经运行旧版时，请先从托盘退出旧版。
3. 右键悬浮窗或点托盘里的「联机房间」，填写昵称，点「异地建房」。
   程序会在后台启动房间服务并申请公网 HTTPS 地址。
4. 建房成功后点「复制邀请」，发完整邀请链接给好友。手机好友在浏览器打开链接，
   输入昵称后加入。Windows 好友把邀请链接粘贴到「邀请链接或房间码」。
   联机期间保持电脑开机，程序可隐藏到托盘。
5. 返回计数器后也能找回邀请。重新打开「联机房间」可查看完整链接；
   也可以右键托盘图标或悬浮窗，直接点「复制房间邀请」。

二、只在本机试用
在程序的「联机房间」填写昵称并点「本机建房」。用桌面程序查看房间，
或复制邀请链接后在同一台电脑的浏览器里打开。已经有房间服务的话，
可填入服务地址并点「在已有服务建房」。

三、手机切应用、锁屏或关页
加入房间并设置班次后，勾选「关页后继续同步」，等页面显示「已开启」。
房间服务会估算当天进度到手机当地午夜。想继续共享金额，还要开启
「共享今日已赚」。同一浏览器重新打开同一网址时，可恢复有效的房间连接。
点「退出房间」会移除当前成员，之后只记住昵称和房间码供下次手动加入。

四、房间管理和心愿
- 同一个 Windows 用户或浏览器重复加入同一房间，会恢复原成员。换浏览器或
  设备仍会显示为新成员。
- 房主可以在 Windows 的「联机房间」窗口选择成员并点「移除成员」，
  手机端可以直接在成员卡片下移除。房主退出后由下一位成员接任。
- Windows 入房默认共享主程序心愿进度，可在房间里关闭。
  手机设置心愿物品和目标金额后，房间自动显示心愿进度。
  好友能看到预计多久赚到目标。目标价格不会同步到房间。
- Windows 迷你模式单人显示五位小数，多人显示四位；一行按昵称、状态、
  金额、心愿排列，随内容缩放。离线满三分钟或后台满一小时的成员只在完整模式保留。
  主动退出的成员会从房间中移除。鼠标停在昵称、状态或心愿上可看完整内容。
- 成员从上班、午休或加班切到已下班时，Windows 会弹出联机提醒，手机会在打开的
  页面显示提醒。

五、停止和排查
- 从托盘点「退出」会关闭由该程序启动的服务和隧道，房间随之清空。
  下次开启异地房间会生成新的临时地址，需要重新发送邀请。
- Cloudflare 超时会自动重试，最多尝试三次。仍不成功可先点「本机建房」，
  或换网络后重试「异地建房」。
- 如需查看连接日志，可单独运行 start-online.cmd 或 start-local.cmd。
  这两个命令窗口是备用启动方式。用 Ctrl+C 停止从命令窗口启动的服务。
- 手机走移动数据打开邀请链接可以确认外网能访问。邀请链接含房间码，
  只发给希望加入的人。
