# 牛马脱敏器联机房间

Windows 悬浮窗与手机浏览器可进入同一个房间。房间里每秒更新成员的工时进度、状态和计划下班倒计时。每个人可单独开启「共享今日已赚」。

Windows 加入房间后，点「返回计数器」即可在首页一起看自己和好友的计数器。迷你模式也显示好友，在悬浮窗右键菜单里可以勾选「迷你模式只显示自己」。开启防窥会隐藏悬浮窗上的金额，并关闭自己的对外金额共享。

手机网页可直接设置班次并在首页计薪。「精简显示」收起个人进度区，保留金额和工作状态。已有房间服务更新网页时，需要重启服务来加载新页面；重启会清除当前房间。

同一 Windows 用户或同一浏览器重复加入同一房间时会恢复原成员。换设备、换浏览器或清空浏览器数据，仍会以新成员加入。房主可在 Windows 的「联机房间」管理窗口或手机成员列表移除成员；原邀请仍可用来重新加入。

在 Windows 房间中开启「共享主程序的心愿进度」，好友计数器旁会显示主程序的心愿提示。提示里的金额差额不会对外分享。手机可在设置中填写心愿物品与目标金额，再开启「共享我的心愿进度」。手机端启用关页同步后，也会继续更新当天的心愿倒计时。

## 在本机试用

在源码目录运行 `node room/server.mjs`（Node.js 20 或更新版本）。浏览器打开 `http://127.0.0.1:8080`，然后从 Windows 版悬浮窗的右键菜单或托盘打开「联机房间」。创建房间时填写 `http://127.0.0.1:8080`，并输入昵称。复制的邀请链接可在同一台电脑上的浏览器试用。

Windows 版可直接运行交付的 EXE。要重新编译，在源码目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

## 部署供异地好友使用

首版在一个实例中同时提供手机页面和房间服务。为实例配置一个域名，并用受客户端信任的证书提供 HTTPS。

- 已有 HTTPS 反向代理时，在服务器源码目录构建容器，让代理把该域名的所有路径转发到 `http://127.0.0.1:8080`。代理应保留 `Authorization` 请求头，关闭 API 缓存，并避免记录请求正文或身份令牌。

  ```sh
  docker build -t niuma-room ./room
  docker run -d --name niuma-room --restart unless-stopped -p 127.0.0.1:8080:8080 niuma-room
  ```

- 也可以让容器直接提供 HTTPS。将证书链和私钥以只读方式挂载，保证容器内的 `node` 用户可读取。替换示例中的证书目录，并按证书续期流程重启容器以加载新证书。

  ```sh
  docker build -t niuma-room ./room
  docker run -d --name niuma-room --restart unless-stopped -p 443:8080 \
    -v /absolute/cert-directory:/tls:ro \
    -e NIUMA_CERT=/tls/fullchain.pem -e NIUMA_KEY=/tls/privkey.pem niuma-room
  ```

部署后，在 Windows 的「服务地址」填该 HTTPS 地址，或直接用浏览器打开它。创建房间后复制邀请链接。好友用手机打开链接即可填写昵称加入，也可以将同一个链接粘贴到 Windows 的「邀请链接或房间码」输入框。用房间码时同时填写服务地址。房间码用于邀请，请仅发给希望加入的好友。

## 数据与连接

- 手机端可先加入观看，再在「我的班次与薪资」设置自己的计薪。按成员设备的本地时间计算，支持同日班次、午休、工作日、今日请假或补班、日薪、月薪和加班。
- 加入房间默认关闭金额共享。同步的数据包含昵称、状态、进度和剩余时间，选择共享时附带今日已赚金额与货币符号。公开金额的变化可用于推算赚钱速度。
- 手机开启「关页后继续同步」并等待确认后，切换应用、锁屏或关页时，房间服务会根据上传的预测点估算到当地午夜。默认关闭。金额仍单独控制；开启金额共享时，服务也会接收预计金额，可由此推算计薪速度。日薪和月薪输入仍保存在手机上。重新打开同一网址可回到原房间，退出房间会立即停止代算。
- 未开启关页同步时，后台或关页后服务端 15 秒会显示离线；恢复前台会立即重连。关闭 Windows 房间管理窗口会返回悬浮窗并继续同步。服务重启或房间空置 30 分钟后，房间及成员数据被清除。
- 每个房间最多 20 位成员。服务只使用内存，以单实例方式运行。多个副本各自持有房间，首版需要把该域名的请求发往同一个实例。
